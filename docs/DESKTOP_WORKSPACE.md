# Широкие рабочие страницы

Эксперимент включается только от 1440 CSS-пикселей по ширине.
Для 1440–1799 px боковой отступ — 32 px, от 1800 px — 40 px.
Текст, значки и поля не увеличиваются вместе с монитором.
Ниже 1440 px применяется прежняя раскладка.

| Страница | Раскладка на широком мониторе |
| --- | --- |
| `table.html` | На ширину окна; на 1920 px помещается 31 день без прокрутки |
| `admin.html` | Оба производственных табеля на ширину окна; внутренние полосы прокрутки сохранены |
| `schedule.html` | До 1760 px; от 1680 px сотрудники внутри каждого дня в две колонки |
| `profile.html` | До 1760 px; редактор профиля ограничен 380 px, больше места для итогов и месяцев |
| `settings.html` | До 1680 px; слева табель, сохранение, экран; справа уведомления, приложение, аккаунт |
| `budget.html` | До 1760 px; расходы, обязательные платежи, поступления стоят рядом |
| `budget-help.html` | Более широкое оглавление и внешний контейнер; текст ограничен 900 px |
| `budget-archive.html` | Более широкий контейнер архива; диаграмма категорий сохраняет своё ограничение |
| `updates.html` | Широкая шапка; читаемая центральная лента не растягивается на весь экран |
| `owner.html` | Более широкий список отделов и панель управления |
| `owner-users.html` | Больше места для списка пользователей; панель редактирования не растянута |
| `department-users.html` | Более широкий список сотрудников; модальное редактирование прежнего размера |
| `owner-analytics.html` | Более широкие таблицы и блоки показателей |
| `owner-ideas.html` | Широкий список; текст предложений ограничен 900 px |
| `owner-status.html` | Широкая внешняя сетка, проверкам оставлена удобная ширина |
| `checklist.html` | Больше места для задач, боковая колонка 380 px, быстрые пункты в три колонки |

| `calculator.html` | Больше места для полей и расчёта рядом |
| `help.html` | Широкие разделы и таблицы, абзацы ограничены 900 px |

Шапка на этих страницах выровнена по содержимому. Подсказки крайних
кнопок табелей и овнерки направлены влево, чтобы не выходить за окно.
Логика доступа, сохранения и расчётов не менялась. Другие страницы
сохраняют прежнюю ширину.

## Как откатить только эксперимент

Правила изолированы в `styles/desktop-workspace.css` и работают
только на `body[data-desktop-workspace]`. Для отката отдельной страницы
достаточно убрать этот атрибут у её body. Для полного отката ширины
можно убрать подключения этого файла. Остальные изменения, включая
новогодний режим и оптимизацию медиа, трогать не требуется.

В `js/schedule.js` добавлены только семантические классы списков
`schedule-workers` и `schedule-other-people`; без экспериментальных
стилей они ни на что не влияют.

## Проверка

`tests/desktop-workspace-ui.test.mjs` открывает реальную HTML-разметку
с изолированными тестовыми данными и без записи в Supabase. Проверяются
ширины 390, 1366, 1440, 1920 и 2560 px, выравнивание шапки, размещение
31 дня, колонки и отсутствие изменений геометрии узкого экрана.
Для работы настоящего бюджета отдельно прогоняется `budget-ui.test.mjs`.

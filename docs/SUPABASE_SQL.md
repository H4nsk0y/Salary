# Supabase SQL

Здесь хранятся SQL-скрипты, которые нужно запускать вручную в Supabase SQL Editor.

Правила:
- новые изменения добавлять отдельным файлом с номером и коротким названием;
- SQL по возможности делать idempotent: `if not exists`, `create or replace function`, проверки через `do $$`;
- не использовать `drop` без явной необходимости;
- если скрипт уже запускался, не удалять его из папки: это история изменений БД.
- не сохранять в репозиторий реальные UUID сотрудников, токены, ключи или другие чувствительные данные без явной необходимости.

Пример имени:

```text
001_user_presence.sql
002_owner_reports.sql
003_department_settings.sql
```

Актуальные security-файлы:

- `026_security_hardening.sql` - серверная защита профилей, табелей, уведомлений, push-подписок и аватаров;
- `027_security_audit_report.sql` - безопасный отчёт только на чтение по grants, RLS, функциям и триггерам.
- `028_secure_egais_cron.sql` - защищает плановые уведомления ЕГАИС отдельным секретом cron.
- `029_restrict_security_definer_execute.sql` - убирает неявный анонимный доступ к `security definer` RPC, сохраняя доступ авторизованного приложения.
- `030_egais_department_timesheet_view.sql` - дает сотрудникам ЕГАИС безопасный доступ к общему графику без окладов, фактических выплат и прав редактирования.
- `031_staff_voting.sql` - анонимное недельное и месячное голосование за сотрудников с фиксацией победителей и публикацией комментариев после завершения периода.
- `032_shift_checklists.sql` - личные чек-листы смены, защищенные RPC и трехчасовые push-напоминания через cron.
- `033_project_ideas.sql` - предложения пользователей через сайт и защищенный owner-список идей.
- `034_shift_handover_notifications.sql` - адресно уведомляет следующую смену после завершения чек-листа, учитывая дневные и ночные часы и исключая руководителей.
- `035_client_error_logging.sql` - принимает только значимые клиентские ошибки и показывает их владельцу без сетевого шума и чувствительных данных.
- `036_remove_unused_features.sql` - удаляет из действующей базы отключенные чат, задачи, голосование и игровую таблицу вместе с их RPC, уведомлениями и cron-задачей.
- `037_required_egais_checklist_item.sql` - ранее делал пункт «Покрутить марку сменщику» обязательным (это правило отменено в `046`).
- `046_remove_required_egais_checklist_item.sql` - отменяет обязательность этого пункта в базе; уже сохраненные чек-листы и история остаются без изменений.
- `038_idea_review_notifications.sql` - создает адресное уведомление автору идеи, когда владелец отмечает ее рассмотренной.
- `039_compact_timesheet_change_notifications.sql` - сокращает уведомления об изменении графика и оставляет в них только новое состояние дней.
- `045_upcoming_shift_reminders.sql` - восстанавливает совместимость push-теста и запускает ежедневное напоминание о ближайшей смене в 17:00 по Москве.
- `047_department_leaders.sql` - отдельное owner-подтверждение руководителя отдела по UID, автоматический доступ к общему табелю, защита занятой руководящей должности и сохранение независимых прав редактора. Запустить до использования новых инструментов графика.
- `052_timesheet_edit_conflicts.sql` - защищает общий табель от перезаписи более свежих изменений другого редактора.
- `053_shift_unavailable_reports.sql` - позволяет сотруднику отметить собственную смену как недоступную и уведомляет руководителя и редакторов отдела.
- `054_shift_replacement_candidates.sql` - безопасно подбирает коллег с выходным или отсыпным для предварительной договорённости о замене смены.
- `055_contract_odyssey_branch.sql` - добавляет филиал «Контрактное производство «Одиссей»» в ограничения профиля и owner-редактирование.
- `056_owner_product_update_broadcast.sql` - позволяет владельцу вручную сообщить подписанным пользователям о новом обновлении.

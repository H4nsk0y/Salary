# Документация ALVISA SALARY

Все Markdown-документы проекта хранятся в этой папке.

## Основное

- `README.md` - описание проекта, запуск и структура.
- `AGENTS.md` - правила и накопленный контекст разработки.
- `SUPABASE_SQL.md` - порядок применения SQL-миграций.
- `LEGACY_DATABASE_NOTES.md` - сведения о старой структуре базы.

## Аудиты

- `AUDIT-2026-09-06.md` - полный технический аудит от 6 сентября 2026 года.
- `SECURITY_AUDIT.md` - аудит безопасности и необходимые действия.
- `ACCESSIBILITY_AUDIT.md` - аудит доступности интерфейса.

## Edge Functions

- `FUNCTION_SEND_PUSH_NOTIFICATIONS.md` - отправка push-уведомлений.
- `FUNCTION_SEND_EGAIS_FILE_REMINDERS.md` - напоминания ЕГАИС.
- `FUNCTION_SEND_SHIFT_CHECKLIST_REMINDERS.md` - напоминания по чек-листам.
- `FUNCTION_OWNER_ACCOUNT_ADMIN.md` - серверное управление учетными записями.

## Рабочие расчеты

- `Двойные.md` - контрольный расчет оплаты праздничной смены и наблюдения по фактическим выплатам.

# ALVISA SALARY

**ALVISA SALARY** — веб-приложение для расчёта заработной платы и ведения табеля учёта рабочего времени для предприятия ALVISA. Проект ориентирован на практическое применение: пользователь фиксирует отработанные часы, отмечает особые дни и получает сводные показатели за месяц, а также историю по месяцам и годовую динамику переработок.

## Возможности

### Калькулятор зарплаты
- Расчёт итоговой суммы на основе введённых параметров.
- Отдельный вывод ключевых составляющих расчёта (база, премиальная часть, ночные).
- Оценка аванса и остатка на основе первой половины месяца.

### Табель учёта рабочего времени
- Ввод часов по каждому дню месяца (дневные и ночные).
- Поддержка специальных отметок (отпуск, больничный).
- Отметка особых дней (праздничные и сокращённые).
- Автоматические итоги по месяцу: отработано, ночные часы, нормы и баланс времени.
- Экспорт и сохранение табелей по месяцам в аккаунте пользователя.

### Личный кабинет
- Профиль пользователя и базовые настройки (включая оклад).
- Список табелей по месяцам: открытие и удаление.
- Годовой баланс переработок и контроль ограничения по нормативу.

## Техническая архитектура (прототип)

- **Frontend:** HTML + JavaScript (ES modules), локально собранный Tailwind CSS.
- **Хранение данных и авторизация:** Supabase (Auth + Postgres).
- **Деплой:** GitHub Pages (статический хостинг).

Ключевой принцип проекта — единая логика расчёта, используемая как в калькуляторе, так и в табеле, чтобы результаты совпадали при одинаковых входных данных.

## Страницы

- `index.html` — главная страница
- `calculator.html` — калькулятор зарплаты
- `table.html` — табель учёта рабочего времени
- `schedule.html` — смены отдела
- `checklist.html` — личный чек-лист смены
- `profile.html` — личный кабинет
- `login.html` — вход и регистрация
- `admin.html` — администрирование 

## Структура репозитория

- `calc.js` — ядро расчётов и общие константы
- `table.js` — логика табеля и агрегирование данных по месяцу
- `profile.js` — профиль и годовые сводные показатели
- `auth.js` — операции авторизации (Supabase Auth)
- `db.js` — операции чтения/записи данных (Supabase PostgREST)
- `supabaseClient.js`, `config.js` — инициализация клиента Supabase и конфигурация

## Развёртывание

Проект рассчитан на публикацию как статический сайт. Для работы в продуктиве достаточно:
1. Настроить Supabase (Auth + таблицы/политики доступа).
2. Указать параметры Supabase в `config.js`.
3. Опубликовать репозиторий через GitHub Pages.

Перед публикацией изменений интерфейса:

```powershell
npm.cmd ci
npm.cmd run check
```

Команда пересобирает `styles/tailwind.css` и запускает регрессионные тесты. GitHub Actions выполняет ту же проверку при push.

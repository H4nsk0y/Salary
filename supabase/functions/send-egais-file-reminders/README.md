# send-egais-file-reminders

Edge Function для напоминаний сотрудникам отдела ЕГАИС, которые фактически стоят в табеле на текущую дату:

- 13:00 по Москве — проверить, ушли ли суточные; получают все сотрудники со сменой в этот день;
- 00:15 по Москве — проверить суточные на правильность; получают сотрудники с полной ночной сменой `2/5` или `4/7`;
- 08:30 по Москве — запасное напоминание дневной смене, только если в этот день нет ни одной полной ночной смены.

Получатели должны одновременно:

- состоять в `department_members` с `department_key = 'egais'`;
- включить настройку `egais_file_reminders_enabled`;
- иметь активную push-подписку.
- иметь подходящую смену в сохранённом табеле на текущую дату.

Перед использованием:

1. Убедиться, что VAPID secrets уже настроены.
2. Задеплоить функцию:

```powershell
supabase.cmd functions deploy send-egais-file-reminders
```

3. Для первоначальной настройки выполнить `supabase-sql/013_egais_file_reminders.sql`.
4. Для перехода на отбор по сменам выполнить `supabase-sql/023_egais_shift_aware_reminders.sql`.

# Supabase SQL

Здесь хранятся SQL-скрипты, которые нужно запускать вручную в Supabase SQL Editor.

Правила:
- новые изменения добавлять отдельным файлом с номером и коротким названием;
- SQL по возможности делать idempotent: `if not exists`, `create or replace function`, проверки через `do $$`;
- не использовать `drop` без явной необходимости;
- если скрипт уже запускался, не удалять его из папки: это история изменений БД.
- не сохранять в репозиторий реальные UUID сотрудников, токены, ключи или другие чувствительные данные без явной необходимости.

Пример имени:

```text
001_user_presence.sql
002_owner_reports.sql
003_department_settings.sql
```
